# SmartTask DevOps Project

Projet d'automatisation CI/CD et de conteneurisation pour l'application SmartTask.

## Architecture
L'application se compose de 3 microservices :
- Frontend : Interface utilisateur
- Backend : API REST Node.js
- Base de données : PostgreSQL

## Fonctionnalités DevOps
- Docker & Docker Compose : Conteneurisation et déploiement local
- Git & GitHub : Branches main (Prod) et Dev
- Jenkins CI/CD : Pipeline automatisé avec Docker Hub

## Utilisation en local
Commande pour démarrer : docker-compose up -d
